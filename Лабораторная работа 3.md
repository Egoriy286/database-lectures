## Цель работы

- научиться формулировать SQL-запросы `SELECT` с различными условиями отбора (`WHERE`, `AND`, `OR`, `NOT`, `LIKE`, `BETWEEN`, `IN`, `IS NULL`);

- научиться создавать параметрический запрос;

- закрепить различие между DDL и DML на практике;
- научиться выявлять избыточность (дублирование данных) в структуре таблиц и предлагать нормализованную структуру.

> **Важно.** Все запросы в этой лабораторной работе создаются и выполняются **в режиме SQL**, а не через визуальный конструктор запросов (QBE). Вы напрямую пишете текст запроса — это тот же материал, который разбирался на лекции 2, только выполняется он в Access.

## Как переключиться в режим SQL

1. На вкладке **Создание** нажмите **Конструктор запросов**.
2. В диалоговом окне добавления таблиц нажмите **Закрыть** (таблицу добавлять через GUI не нужно).
3. На вкладке **Конструктор** найдите кнопку **SQL** (группа «Результаты» / переключатель режимов) и нажмите её — откроется пустое окно, куда вводится текст запроса.
4. Наберите SQL-запрос и запустите его кнопкой **Выполнить** (значок `!`).
5. Сохраните запрос (`Ctrl+S`) под именем, указанным в задании.

Каждый следующий запрос удобнее создавать так же — через **Конструктор запросов → Закрыть → SQL**, либо скопировать предыдущий запрос и изменить его текст.

## Шпаргалка: операторы WHERE в Access SQL

| Что нужно | Оператор | Пример |
|---|---|---|
| Сравнение | `=`, `<>`, `>`, `<`, `>=`, `<=` | `[Группа] = 'КОМ-365'` |
| И то, и другое | `AND` | `[Группа] = 'КОМ-365' AND [Телефон] IS NOT NULL` |
| Любое из двух | `OR` | `[Группа] = 'КОМ-365' OR [Группа] = 'КОМ-366'` |
| Отрицание | `NOT` | `NOT [Группа] = 'КОМ-365'` |
| Диапазон | `BETWEEN ... AND ...` | `[Экзамен 1] BETWEEN 3 AND 5` |
| Множество значений | `IN (...)` | `[Группа] IN ('КОМ-365','КОМ-366')` |
| Отсутствие значения | `IS NULL` / `IS NOT NULL` | `[Телефон] IS NULL` |
| Шаблон строки (Access SQL) | `LIKE` | `[Фамилия] LIKE 'Ив*'` |
| Сортировка | `ORDER BY` | `ORDER BY [Фамилия], [Имя]` |

**Про `LIKE` в Access SQL (это не «стандартный» SQL!):**
`*` — любое количество любых символов; `?` — ровно один любой символ; `#` — ровно одна цифра; `[А-И]` — один символ из диапазона. Пример: `LIKE [А-И]*` находит фамилии, начинающиеся с букв от А до И.

## Часть 6. Изменяющие запросы (INSERT / UPDATE / DELETE)

Здесь важна аккуратность: вы будете реально изменять данные в таблице. Выполняйте пункты строго по порядку и на **одной и той же** добавленной записи.

### 6.1. Добавление записи

```sql
INSERT INTO [Студенты]
    ([Фамилия], [Имя], [Группа])
VALUES
    ('Сидоров', 'Алексей', 'КОМ-365');
```

Выполните этот запрос (сохранять его не обязательно, но можно под именем `6_1_Insert`). Откройте таблицу `Студенты` и убедитесь, что запись появилась.

### 6.2. Изменение записи

```sql
UPDATE [Студенты]
SET [Группа] = 'КОМ-366'
WHERE [Фамилия] = 'Сидоров'
  AND [Имя] = 'Алексей';
```

Выполните и убедитесь, что группа у созданного студента изменилась. Сохраните под именем `6_2_Update`.

### 6.3. Удаление именно этой записи

```sql
DELETE FROM [Студенты]
WHERE [Фамилия] = 'Сидоров'
  AND [Имя] = 'Алексей';
```

Выполните и убедитесь, что запись удалена. Сохраните под именем `6_3_Delete`.
