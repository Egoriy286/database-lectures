# Лекции и лабораторные работы по базам данных

Учебный репозиторий с лекционными материалами и лабораторными работами по дисциплине, посвящённой проектированию и использованию баз данных.

Работу выполнил магистрант 2 курса Северо-Восточного федерального университета имени М. К. Аммосова (СВФУ) — **Monastyrev Egoriy**.

## Содержание

- лекционные материалы по основам баз данных и SQL;
- проектирование структуры базы данных и ER-моделей;
- SQL-запросы в Microsoft Access;
- выборка, сортировка и изменение данных;
- вычисляемые и параметрические запросы;
- основы нормализации и устранения избыточности данных;
- лабораторные работы с базой данных `Student`.

## Структура репозитория

```text
.
├── lecture1.pdf                         # Лекция 1
├── lecture2.pdf                         # Лекция 2
├── laba1.pdf                             # Лабораторная работа 1
├── laba2.pdf                             # Лабораторная работа 2
├── Лабораторная работа 3.md               # Методические материалы к работе 3
├── Лабораторная работа 3-old.docx        # Предыдущая версия работы 3
├── src/
│   ├── Access Лабораторная работа № 1-1.doc
│   ├── Access Лабораторная работа № 2-2.DOC
│   └── tex/                              # Исходники презентаций LaTeX
└── LICENSE
```

## Используемые технологии

- **Microsoft Access 2016** — выполнение лабораторных работ и запросов;
- **SQL** — работа с данными и структурами таблиц;
- **LaTeX / Beamer** — подготовка лекционных презентаций;
- **TikZ** — создание схем и ER-диаграмм.

## Как использовать материалы

Готовые материалы доступны в формате PDF в корне репозитория. Исходники презентаций находятся в `src/tex/`. Лабораторные работы по Microsoft Access можно использовать как инструкции для создания учебной базы данных и выполнения SQL-запросов.

Для работы с исходниками LaTeX требуется установленный LaTeX-дистрибутив с поддержкой Beamer, TikZ и русской локали. Файлы формата `.doc` и `.docx` открываются в Microsoft Word или совместимом офисном пакете.

# Database Lectures and Laboratory Work

An educational repository containing lecture materials and laboratory assignments on database design and usage.

This work was prepared by a **second-year master’s student at North-Eastern Federal University named after M. K. Ammosov (NEFU)** — **Monastyrev Egoriy**.

## Contents

- lecture materials on databases and SQL fundamentals;
- database structure and ER-model design;
- SQL queries in Microsoft Access;
- data selection, sorting, and modification;
- calculated and parameter queries;
- fundamentals of normalization and data redundancy reduction;
- laboratory assignments based on the `Student` database.

## Repository structure

```text
.
├── lecture1.pdf                         # Lecture 1
├── lecture2.pdf                         # Lecture 2
├── laba1.pdf                             # Laboratory work 1
├── laba2.pdf                             # Laboratory work 2
├── Лабораторная работа 3.md               # Materials for laboratory work 3
├── Лабораторная работа 3-old.docx        # Previous version of laboratory work 3
├── src/
│   ├── Access Лабораторная работа № 1-1.doc
│   ├── Access Лабораторная работа № 2-2.DOC
│   └── tex/                              # LaTeX presentation sources
└── LICENSE
```

## Technologies

- **Microsoft Access 2016** — laboratory assignments and query execution;
- **SQL** — working with data and table structures;
- **LaTeX / Beamer** — preparing lecture presentations;
- **TikZ** — creating diagrams and ER models.

## Usage

Ready-to-use materials are available as PDF files in the repository root. Presentation sources are located in `src/tex/`. The Microsoft Access laboratory assignments can be used as guides for creating a training database and executing SQL queries.

To compile the LaTeX sources, install a LaTeX distribution with Beamer, TikZ, and Russian-language support. The `.doc` and `.docx` files can be opened in Microsoft Word or a compatible office suite.
